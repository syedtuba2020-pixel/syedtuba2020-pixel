# Biomedical & Bioinformatics Projects

## About

This repository contains selected projects in biomedical data analysis,
computational biology, and biological data handling using Python and R.

The projects demonstrate practical experience with data collection,
data processing, exploratory analysis, visualization, and interpretation
of biological datasets.

---

## Projects

### 1. BRCA1 & EGFR Gene Analysis

A biomedical data analysis project focused on the BRCA1 and EGFR genes,
with emphasis on biological data interpretation and computational analysis.

**Tools:** Python / R  
**Area:** Bioinformatics, cancer biology, biomedical data analysis

📄 **Project Report:** `PROJECT brca1. and egfr. gene.pdf`

### 2. Biomedical Data Collector

### 3. Plant Growth Dataset Analysis
